# راهنمای یکپارچهٔ اتصال API، مصرف و کنترل هزینه — RAG_finance

**نسخه:** v1.0  
**تاریخ ثبت:** ۱ نوامبر ۲۰۲۶ — ۱۰ آبان ۱۴۰۵  
**دامنه:** فقط پروژهٔ RAG_finance و شواهد همین گفتگو، تا خروجی C059 از NB22E.  
**نوع سند:** راهنمای عملیاتی و دفتر خلاصهٔ مصرف؛ نه صورتحساب، مجوز عمومی هزینه، یا Runner اجراشده.

## ۱. وضعیت فعلی و تصمیم هزینه

- اتصال embedding آروان با نام پیکربندی‌شدهٔ `Bge-m3` در C054 آزموده شده؛ دو بردار ۱۰۲۴بعدی و ۲۶ توکن ورودی ثبت شده است.
- C055 برای ۳۴۸۸ قطعه و ۵۳۳ سؤال، ۲۵۲ درخواست embedding اجرا کرده است.
- C059 برای ۱۰ سؤال ثابت و دو مدل، مجموعاً ۲۰ درخواست رتبه‌بندی اجرا کرده است.
- هیچ ادامه‌ای از ۱۰ به ۳۰ سؤال مجاز به اجرای خودکار نیست.
- نتیجهٔ کیفی فعلی، ادامهٔ همین آزمایش پولی یا خرید مدل بعدی را توجیه نکرده است.
- بررسی احتمالیِ بازگرداندن شناسه‌های مثال پرامپت هنوز انجام نشده؛ کپی مثال، علت اثبات‌شدهٔ شکست نیست.
- baseline و کش‌ها حفظ شوند. بازخوانی و تحلیل محلی بر ارسال پولی تازه اولویت دارد.
- این سند هیچ پرداخت، شارژ حساب، نصب، تماس API یا تغییر درگاه انجام نداده است.

## ۲. تنظیمات اتصال و محل اسرار

### تنظیمات استفاده‌شده در اجراهای اخیر

فایل تنظیمات روی مک، `.env` ریشهٔ مخزن است:

```dotenv
# مقدار واقعی فقط در فایل محلی باشد؛ این نمونه کلید واقعی ندارد.
ARVAN_GATEWAY_URL=https://YOUR_GATEWAY_HOST/v1
ARVAN_GATEWAY_API_KEY=YOUR_NEW_PRIVATE_KEY

# تنظیم قدیمی پروژه؛ تغییر آن الزاماً مدل سل‌های NB22E را عوض نمی‌کند.
ARVAN_GATEWAY_MODEL=GPT-5-Mini
```

**مهم:** در C054، C055 و C059 نام مدل داخل قرارداد/بدنهٔ درخواست تعیین شده است؛ صرف تغییر `ARVAN_GATEWAY_MODEL` مدل آن سل‌ها را تغییر نمی‌دهد.

متغیرهای قدیمیِ `ARVAN_AI_API_KEY`، `ARVAN_EMBEDDING_URL`، `ARVAN_CHAT_URL` و `ARVAN_CHAT_MODEL` نیز در تنظیمات ارائه‌شده وجود داشتند. مقدار خصوصی یا وضعیت عملی آن مسیرها با این سند احراز نشده است. Runner مسیر قدیمی و Gateway را بی‌صدا با هم مخلوط نکند.

### مسیرها و احراز هویت آزموده‌شده

| کار | روش و مسیر نسبت به پایهٔ دارای /v1 | احراز هویت استفاده‌شده |
|---|---|---|
| embedding در C054/C055 | POST — `ARVAN_GATEWAY_URL.rstrip("/") + "/embeddings"` | `Authorization: apikey <secret>` |
| رتبه‌بندی متنی در C059 | POST — `ARVAN_GATEWAY_URL.rstrip("/") + "/chat/completions"` | همان قالب |
| قالب بدنه | JSON با `Content-Type: application/json` | کلید فقط در Header |

این مسیرها شرح اجرای همین درگاه‌اند؛ به معنی یکسان‌بودن همهٔ ارائه‌دهندگان نیستند. تغییر تصادفی مسیر، افزودن دوبارهٔ `/v1`، تغییر `apikey` به `Bearer` یا تعویض حدسی مدل برای عبور از خطا ممنوع است.

### حفاظت از کلید

کلید درگاه یک‌بار در همین گفتگو افشا شد. تعویض آن توصیه شده، اما **تعویض انجام‌شده تأیید نشده است**.

- کلید قبلی در پنل باطل و کلید تازه فقط در `.env` ذخیره شود.
- کلید، Header کامل، محتوای `.env` و URL خصوصی در چت، خروجی نوت‌بوک یا Git چاپ نشوند.
- `.env` و `.env.*` از Git خارج باشند؛ `.env.example` فقط مقادیر نمونه داشته باشد.
- ignore کردن فایل، اسرار قبلاً commitشده را از تاریخچه حذف نمی‌کند.
- در گزارش‌ها نام متغیر و fingerprint مسیر کافی است.
- تنظیمات محلی پروژه بر مقدار قدیمیِ به‌جامانده در Kernel اولویت داشته باشد.

### مشاهدهٔ نام متغیرها بدون نمایش مقدار

```python
from pathlib import Path

p = Path(ROOT) / ".env"
wanted = {
    "ARVAN_GATEWAY_URL",
    "ARVAN_GATEWAY_API_KEY",
    "ARVAN_GATEWAY_MODEL",
}

found = set()
for raw in p.read_text(encoding="utf-8-sig").splitlines():
    line = raw.strip()
    if line.startswith("export "):
        line = line[7:].strip()
    name, separator, value = line.partition("=")
    if separator and name.strip() in wanted and value.strip():
        found.add(name.strip())

for name in sorted(wanted):
    print(name, "SET" if name in found else "MISSING")
```

این کد فقط وجود مقدار را نشان می‌دهد؛ سلامت اتصال را ثابت نمی‌کند.

## ۳. تفاوت کار مدل‌ها

| مدل/اجرا | کار | توضیح |
|---|---|---|
| E5-small محلی | embedding و بازیابی | API پولی ندارد؛ زمان و منابع مک مصرف می‌کند |
| `Bge-m3` آروان | embedding | مدل آمادهٔ سرویس؛ بردارهای ۱۰۲۴بعدی دریافت شدند |
| `bge-reranker-v2-m3` محلی | امتیازدهی جفت سؤال–قطعه | با مدل embedding بالا متفاوت است |
| `DeepSeek-V4-Flash` | داوری قبلی و رتبه‌بندی متنی C059 | نام پیکربندی‌شدهٔ درگاه |
| `GPT-5-Mini` | رتبه‌بندی متنی C059 | نام پیکربندی‌شدهٔ درگاه |

صفحهٔ بازارچه/درگاه آروان که ارائه شد، سرویس استنتاج آماده است؛ شواهدی از سرور GPU اختصاصی یا قابلیت آموزش مدل در آن تصاویر وجود ندارد. «استفاده از مدل ابری» با «آموزش مدل روی سرور ابری» یکی نیست.

نام مدل در پاسخ، احراز مستقل وزن‌ها یا revision واقعی backend نیست.

## ۴. تعرفه‌ها و واحد پول

**یک تومان = ۱۰ ریال.** مبالغ زیر همگی به **تومان برای یک‌میلیون توکن** تبدیل شده‌اند.

| مدل | ورودی | خروجی | منبع و اعتبار |
|---|---:|---:|---|
| BGE-M3 آروان | ۴٬۰۰۰ | در تصویر صفر | تصویر پنلِ ارائه‌شده در همین گفتگو؛ صورتحساب تأیید نشده |
| DeepSeek-V4-Flash | ۴۳٬۶۸۰ | ۸۷٬۳۶۰ | تعرفهٔ تاریخیِ فایل پروفایل پروژه؛ قیمت جاری تأیید نشده |
| GPT-5-Mini | ۷۸٬۰۰۰ | ۶۲۴٬۰۰۰ | همان منبع تاریخی؛ قیمت جاری تأیید نشده |
| Embedding-3-Large | ۴۰٬۰۶۰ | در این سند مصرف ندارد | قیمت ورودیِ تصویر بازارچه؛ برای C055 استفاده نشد |
| Gemini-embedding-001 | ۴۶٬۸۰۰ | در این سند مصرف ندارد | قیمت ورودیِ تصویر بازارچه؛ استفاده نشد |

قیمت مستقیم سازنده، قیمت درگاه آروان فرض نشود. مالیات، کارمزد، نرخ تبدیل، تخفیف، تعرفهٔ کش، گردکردن و سایر اقلام صورتحساب از شواهد فعلی احراز نشده‌اند.

### فرمول محاسبهٔ مرجع

```text
هزینهٔ مرجع به تومان =
(توکن ورودی × نرخ ورودی + توکن خروجی × نرخ خروجی) / 1,000,000
```

- `usage.prompt_tokens` و `usage.completion_tokens` مبنای دفتر مصرف ثبت‌شده‌اند.
- نبود usage یا نتیجهٔ نامعلوم به معنی مصرف صفر نیست.
- توکن reasoning، cached input یا سایر جزئیات جدا حفظ شوند؛ بدون تعرفهٔ مستند دوباره به جمع هزینه اضافه نشوند.
- شمارش توکن با tokenizer مدل دیگری، بایت یا کاراکتر، صورتحساب واقعی نیست.
- سناریوی «۱ برابر/۲ برابر توکن جانشین» تحلیل حساسیت است؛ سقف تضمین‌شده نیست.

## ۵. دفتر مصرف این بخش از کار

### اجراهایی که دادهٔ کافی برای محاسبهٔ هزینهٔ مرجع دارند

| اجرا | تعداد درخواست تازهٔ همان اجرا | توکن ورودی | توکن خروجی | هزینهٔ مرجع؛ تومان |
|---|---:|---:|---:|---:|
| C054؛ آزمون embedding | ۱ | ۲۶ | ۰ | ۰٫۱۰۴ |
| C055؛ embedding کل قطعه‌ها و validation533 | ۲۵۲ | ۱٬۰۱۳٬۵۲۸ | ۰ | ۴٬۰۵۴٫۱۱۲ |
| C059؛ DeepSeek روی ۱۰ سؤال | ۱۰ | ۱٬۲۶۱٬۹۲۵ | ۴۵۰ | ۵۵٬۱۶۰٫۲۰ |
| C059؛ GPT-Mini روی همان ۱۰ سؤال | ۱۰ | ۱٬۰۵۴٬۳۹۵ | ۵۳۰ | ۸۲٬۵۷۳٫۵۳ |
| **جمع این ردیف‌ها** | **۲۷۳** | **۳٬۳۲۹٬۸۷۴** | **۹۸۰** | **حدود ۱۴۱٬۷۸۸** |

جمع بالا، **کل هزینهٔ پروژه یا کل حساب آروان نیست**. ریز مبالغ ممکن است به علت گردشدن گزارش‌ها اختلاف چندصدم تومان داشته باشند.

### اجراهای خارج از این جمع

- C046: تعداد ۲۹ فراخوانی تازه ثبت شد؛ ۲۶ پیشنهاد ساختاری معتبر و ۳ مورد معلق. برآورد تاریخیِ پیش از اجرا حدود ۲۰٬۸۸۷ تومان بود؛ **این عدد هزینهٔ واقعی کل C046 نیست**. مصرف و صورتحساب کامل آن در جمع بالا وارد نشده است.
- C058: آماده‌سازی محلی، API صفر. هزینه‌های جدول آن برآورد بودند و نباید دوباره به هزینهٔ اجرا افزوده شوند.
- C049 تا C053 و C056/C057 و بازبینی‌های محلی: API تازهٔ گزارش‌شده صفر؛ هزینهٔ زمان، برق و استهلاک مک قیمت‌گذاری نشده است.
- نمایش دوبارهٔ usage، بازخوانی کش یا بازکردن گزارش، رخداد شبکهٔ جدید محسوب نشود.
- هیچ مبلغی در این سند به‌عنوان «پرداخت بانکی»، «شارژ جدید حساب» یا «صورتحساب قطعی» ثبت نشده است.

## ۶. چه چیزی واقعاً گران بود؟

در C059:

| مدل | هزینهٔ ورودی؛ تومان | هزینهٔ خروجی؛ تومان | سهم ورودی |
|---|---:|---:|---:|
| DeepSeek | ۵۵٬۱۲۰٫۸۸ | ۳۹٫۳۱ | ۹۹٫۹۳٪ |
| GPT-Mini | ۸۲٬۲۴۲٫۸۱ | ۳۳۰٫۷۲ | ۹۹٫۶۰٪ |

**نتیجه:** کاهش سقف خروجی، مسئلهٔ اصلی هزینهٔ این اجرا را حل نمی‌کند. بخش اصلی هزینه از ارسال ۱۸۹ تا ۳۶۲ قطعهٔ کامل برای هر سؤال آمده است.

این نتیجه مجوز بریدن کورکورانهٔ متن نیست: حذف بخش پاسخ‌دهنده می‌تواند کیفیت را بدتر کند. تغییر انتخاب نامزد یا استخراج متن باید قرارداد و ارزیابی مشخص داشته باشد.

## ۷. نتیجهٔ کیفی در برابر پول خرج‌شده

مقایسهٔ C059 روی **همان ۱۰ سؤال**:

| روش | Recall@10 | nDCG@10 | Hit@10 | هزینهٔ مرجع |
|---|---:|---:|---:|---:|
| baseline | ۷۵٪ | ۷۲٫۱۷٪ | ۹۰٪ | این مرحله API تازه ندارد |
| DeepSeek | ۳۵٪ | ۳۶٫۱۳٪ | ۴۰٪ | حدود ۵۵٬۱۶۰ تومان |
| GPT-Mini | ۱۰٪ | ۱۰٪ | ۱۰٪ | حدود ۸۲٬۵۷۴ تومان |

حدود عددی تاریخی: Recall@10 حداقل ۸۵٪ و nDCG@10 حداقل ۷۵٪؛ برای Hit حد مطلق تعیین نشده و عدم افت جدا بررسی می‌شود.

- هیچ‌یک از دو مسیر C059 پذیرفته نشده‌اند.
- JSON معتبر و ۱۰ شناسهٔ مجاز، اثبات رتبه‌بندی درست نیست.
- در پرامپت C058 نمونهٔ D0001 تا D0010 وجود داشت. احتمال بازگرداندن مثال باید با پاسخ‌های کش‌شده سنجیده شود؛ علت شکست هنوز اثبات نشده است.
- تفاوت مدل و تنظیمات مخصوص آن هم‌زمان وجود داشته؛ برابری رفتار reasoning احراز نشده است.
- ۱۰ سؤال Development، آزمون مستقل ریلیز نیست.
- مقایسهٔ C055/C053 روی ۵۳۳ سؤال با C059 روی ۱۰ سؤال مستقیم انجام نشود.
- تعویض مدل به‌تنهایی راهکار اثبات‌شدهٔ بهبود یا صرفه‌جویی نیست.

## ۸. برنامهٔ کاهش هزینه؛ به ترتیب اولویت

| اقدام | فایده | قید |
|---|---|---|
| مصرف کش معتبر قبل از ارسال | حذف ارسال پولی تکراری | هویت متن، مدل، مسیر و قرارداد باید مطابق باشد |
| بررسی محلی خروجی C059 | تشخیص کپی مثال و خطای نگاشت بدون هزینهٔ API | این بررسی هنوز اجرا نشده |
| ادامه‌ندادن خودکار ۲۰ سؤال باقی‌مانده | جلوگیری از توسعهٔ آزمایش ناموفق | مقدار صرفه‌جویی قطعی اعلام نشود؛ هزینهٔ فرضی صورتحساب نیست |
| حذف ورودی واقعاً تکراری در قرارداد جدید | کاهش توکن ورودی | متن یکسان و نقش مؤثر یکسان؛ شناسه‌های اصلی حفظ شوند |
| انتخاب نامزد کمتر یا متن کوتاه‌تر | کاهش عامل اصلی هزینه | احتمال ازدست‌رفتن شاهد باید سنجیده شود؛ هنوز روش موفقی تأیید نشده |
| پایلوت فنی روی ورودی نماینده قبل از بستهٔ بزرگ | کنترل Schema، شناسه و هزینه | فقط JSON سالم کافی نیست؛ یک کنترل محتوایی/رتبه‌بندی محلی نیز لازم است |
| یک مدل پس از آزمایش مقایسه‌ای معتبر | حذف پرداخت دوگانه در ادامه | C059 فعلی مبنای انتخاب برنده نیست |
| ثبت تعرفهٔ کش ارائه‌دهنده | امکان محاسبهٔ دقیق‌تر | تخفیف یا cache hit سمت سرور را فرض نکنیم |
| سقف بودجهٔ سمت ارائه‌دهنده، اگر در حساب موجود باشد | کنترل سخت‌تر هزینه | وجود یا تنظیم این قابلیت برای حساب فعلی تأیید نشده |

**در وضعیت فعلی:** ادامهٔ رایگان از کش و کنترل طراحی، مقدم بر هر درخواست تازه است. اجرای مجدد C059 با هدف «شاید این بار بهتر شود» برنامهٔ کاهش هزینه نیست.

## ۹. سقف‌ها: چه چیزی واقعاً تضمین شده است؟

| کنترل | C055 | C059 |
|---|---|---|
| دامنه | ۴۰۲۱ ورودی embedding | ۱۰ سؤال × ۲ مدل |
| تعداد درخواست برنامه‌ریزی‌شده | ۲۵۲ | ۲۰ |
| هم‌زمانی | ۱ | ۱ |
| retry خودکار | صفر | صفر |
| سقف توقف محلیِ مرجع | ۲۰٬۰۰۰ تومان | ۳۰۰٬۰۰۰ تومان |
| مبنای رزرو | ۸۱۹۲ توکن به‌ازای هر ورودی، بر اساس ظرفیت اعلام‌شده | ۲ برابر توکن جانشین + سقف خروجی |
| سقف سخت صورتحساب آروان | تأیید نشده | تأیید نشده |

محدودیت درخواست‌ها را کد کنترل می‌کند؛ اما رزرو بر اساس جانشینِ توکن و تعرفهٔ تاریخی، **سقف قطعی پول برداشت‌شده نیست**. مصرف درخواست جاری، نتیجهٔ نامعلوم یا تغییر تعرفه می‌تواند در حساب متفاوت منعکس شود.

سیاست مجوز تاریخی پروژه در سند 03 باقی است: در دامنهٔ مجاز، زیر ۱۰۰هزار تومان اجازهٔ تکراری لازم نیست؛ از ۱۰۰ تا کمتر از ۵۰۰هزار، مبلغ و دامنه اعلام می‌شود؛ بالای ۵۰۰هزار نیاز به اجازهٔ صریح دارد. مرز دقیق ۵۰۰هزار در سند قبلی تعارض دارد؛ این فایل آن تعارض را حل یا مجوز عمومی ایجاد نمی‌کند. دستور صریح کاربر در همین جلسه بر راهنمای عمومی مقدم است.

کاربر در C059 اجرای ۱۰ سؤال با هر دو مدل را مجاز کرده بود؛ این مجوز به اجرای ۳۰ یا ۵۳۳ سؤال تعمیم داده نشود.

## ۱۰. ترتیب صحیح اجرای پولی و ادامه از کش

1. ورودی، جمعیت، متن، مدل، مسیر، تنظیمات، Schema خروجی و قیمت مرجع تثبیت شوند.
2. کار قطعی مانند join، هش، شمارش، metric و بررسی index محلی انجام شود.
3. همهٔ کش‌ها و تلاش‌های قبلی پیش از ارسال تازه تطبیق داده شوند.
4. رزرو یکتا و attempt پیش از Dispatch ثبت شود.
5. redirect و retry پنهان SDK غیرفعال باشند.
6. پاسخ خام، HTTP status و مدت درخواست پیش از Parse ذخیره شوند.
7. usage به همان رخداد یکتای شبکه متصل شود؛ نتیجه و هزینه دو دفتر مستقل باشند.
8. Schema، شناسه‌ها و معنای موردنیاز خروجی جدا بررسی شوند.
9. محاسبات از دیسک بازخوانی و کنترل شوند.
10. درخواست نامعلوم یا ناموفق با حذف attempt دوباره اجرا نشود.

### برخورد با خطا

| حالت | اقدام |
|---|---|
| خطای محلی قبل از ثبت/ارسال درخواست | اصلاح کد؛ هزینهٔ آن اجرای مشخص فقط با شواهد تعیین شود |
| ۴۰۱/۴۰۳/۴۰۴ | توقف؛ بررسی تنظیمات واقعی، بدون تعویض حدسی Header یا مسیر |
| ۴۲۹ | توقف طبق سیاست جاری؛ افزایش worker راه‌حل پیش‌فرض نیست |
| timeout/قطع ارتباط پس از Dispatch | OUTCOME_UNKNOWN؛ احتمال مصرف حفظ شود، بدون resend خودکار |
| HTTP200 با JSON یا شناسهٔ غلط | raw حفظ شود؛ مصرف ممکن است انجام شده باشد |
| پایان خروجی با length | آن را خروجی کامل تلقی نکنیم؛ سقف/قالب بررسی شود، بدون retry خودکار |
| usage ناموجود | هزینه صفر ثبت نشود |
| کش معتبر | بدون تماس شبکه مصرف شود |
| یک پرونده خراب | کل بسته یا همهٔ پاسخ‌های سالم دوباره اجرا نشوند |

خطای خواندن question در نخستین C055 پیش از Dispatch رخ داد و اصلاح شد: فیلد معتبر متن سؤال `evaluation_content.question` است. از فیلد بالایی `question` بدون بررسی schema استفاده نشود.

## ۱۲. تطبیق با پرداخت و صورتحساب

برای ثبت «پرداخت واقعی»، این موارد جدا لازم‌اند:

| سند | چه چیزی را ثابت می‌کند؟ | در شواهد فعلی |
|---|---|---|
| رسید شارژ/پرداخت با زمان و شناسه | ورود وجه به حساب | در این جمع ارائه نشده |
| صورتحساب یا export مصرف provider | مبلغ صورتحساب‌شده و بازه | تأیید نشده |
| usage پاسخ API | مصرف اعلام‌شده برای درخواست | برای ردیف‌های جدول بخش ۵ موجود |
| قرارداد/تصویر تعرفه با تاریخ | نرخ تبدیل مصرف به هزینه | BGE تصویر؛ DeepSeek/Mini تاریخی |
| مانده کیف پول | وضعیت لحظه‌ای حساب | معادل هزینهٔ همین آزمایش نیست |

اختلاف دو تصویر از ماندهٔ کیف پول، بدون کنترل سایر مصرف‌ها، مالیات و شارژها، هزینهٔ C059 را ثابت نمی‌کند. دادهٔ شخصی پرداخت و شماره‌های مالی لازم نیست در چت عمومی یا Git قرار گیرد.

تا دریافت صورتحساب، برچسب درست **«هزینهٔ مرجع بر اساس usage»** است؛ نه «مبلغ قطعی پرداخت‌شده».

## ۱۳. ماشین‌حساب آفلاین هزینه

این تابع هیچ API اجرا نمی‌کند و به کلید دسترسی ندارد:

```python
from decimal import Decimal, ROUND_HALF_UP

REFERENCE_TARIFFS = {
    "Bge-m3": {"input": "4000", "output": "0"},
    "DeepSeek-V4-Flash": {"input": "43680", "output": "87360"},
    "GPT-5-Mini": {"input": "78000", "output": "624000"},
}

def reference_cost_toman(model, input_tokens, output_tokens):
    for value in (input_tokens, output_tokens):
        if not isinstance(value, int) or isinstance(value, bool) or value < 0:
            raise ValueError("Token counts must be known nonnegative integers.")
    if model not in REFERENCE_TARIFFS:
        raise ValueError("Unknown reference tariff.")
    price = REFERENCE_TARIFFS[model]
    amount = (
        Decimal(input_tokens) * Decimal(price["input"])
        + Decimal(output_tokens) * Decimal(price["output"])
    ) / Decimal("1000000")
    return {
        "model": model,
        "reference_cost_toman": str(amount.quantize(
            Decimal("0.01"), rounding=ROUND_HALF_UP
        )),
        "current_tariff_verified": False,
        "provider_invoice_verified": False,
    }

print(reference_cost_toman("DeepSeek-V4-Flash", 1261925, 450))
print(reference_cost_toman("GPT-5-Mini", 1054395, 530))
```

برای محاسبهٔ صورتحساب نهایی، نرخ معتبر همان زمان جایگزین شود؛ نسخهٔ تعرفهٔ تاریخی پاک نشود.
