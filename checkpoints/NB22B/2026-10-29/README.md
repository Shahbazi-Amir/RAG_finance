# NB22B — پشتیبان ادامهٔ ساخت

این شاخه برای بازیابی کار پس از قطع چت است؛ نسخهٔ نهایی یا پذیرش محصول نیست.

## فایل پشتیبان
`NB22B_build_continuation_checkpoint.zip` شامل نوت‌بوک فعلی، ماژول‌های ساخت، چک‌لیست‌ها، گزارش آزمون‌ها و وضعیت ادامه است. داده‌های خام، کلید API و مدل‌ها داخل آن نیستند.

پس از استخراج، ابتدا `inspection/NB22B_resume_state.json` و `deliverables/NB22B_build_continuation_checkpoint_fa.md` خوانده شوند. کد منبع ساخت از نوت‌بوک فعلی جدیدتر است؛ پیش از استفادهٔ نهایی باید مونتاژ و آزمون شود.

## ادامهٔ دقیق
1. آزمون افزونهٔ نسخه‌دار پرامپت در product_engine.py و رد parent/policy نامنطبق.
2. تکمیل پوشش فایل‌های الزامی در inventory فنی.
3. اجرای assemble.py، آزمون تغییرات و fresh-process execution.
4. اجرای finalize_delivery.py فقط با fingerprint منطبق گزارش‌ها.
5. تحویل نوت‌بوک با محدودیت‌های واقعی؛ پذیرش کیفیت هنوز برقرار نشده است.

۱۴ اقدام و ۶۴ زیرکار دامنهٔ نوت‌بوک هستند؛ ثبت این بسته به معنی تکمیل همهٔ آن‌ها نیست. آزمون‌های مصنوعی اثبات عملکرد واقعی مدل یا اجرای Mac نیستند.
هیچ API واقعی مدل در این محیط فراخوانی نشده است. بودجهٔ ۱٬۶۵۰٬۰۰۰ تومان فقط برای بررسی شکاف معنایی تاریخی است؛ مجوز تولید جدید یا holdout نیست. تعویق health check قبلی حفظ می‌شود.

شاخه از rag-phase2 در commit 856a2d3b8e53151e28924bb61ed9514b7b14ce03 ایجاد شده است. داده‌های بررسی‌شده قبلی بر اساس snapshot ec35ae711e649445db5d55fd642065e1308ba43d بودند؛ به‌روزرسانی شاخهٔ اصلی به معنای بازبینی مجدد آن داده‌ها نیست.
