## قرارداد اقدام

متن اقدام ۳۶ در چک‌لیست:

> بدون Source diversity؛ شناسایی سیاست واقعاً فعال در NB18/مسیر نهایی، نه فقط گزینهٔ اختیاری NB16.

هدف، مقایسهٔ سیاست فعال ساخت Context با نسخه‌ای است که محدودیت مرتبط با منبع در آن حذف شده است. باید روشن باشد دقیقاً کدام جزء تغییر می‌کند: سقف منبع، سقف سند، یا سیاست دیگری. حذف یک سقف مشخص نباید حذف تمام سیاست‌های تنوع نامیده شود.

شرط عمومی Ablationها: تغییر واقعی جزء، کنترل سایر عوامل، اثر و محدودیت ثبت شود؛ مقایسهٔ بی‌تغییر یا Proxy جای Ablation کامل معرفی نشود. انتخاب تنظیمات روی Development باشد و Artifactهای آزمایش از نسخهٔ فریز‌شده جدا نگه داشته شوند.

## سابقهٔ مرتبط برای جلوگیری از دوباره‌کاری

در ممیزی قبلی همین گفتگو، سیاست نهایی NB18 در محدودهٔ سل‌های C075 تا C079 با سقف منبع ۸ و سقف سند ۵ شناسایی شده بود. تنظیم آزمایشی پیشین ۸/۶ نباید خودکار به‌جای سیاست نهایی استفاده شود.

این سابقه در این نوبت دوباره از فایل اصلی بازخوانی نشده و نتیجهٔ Ablation جدید نیست. کاربرد آن معرفی محل شروع تطبیق است: سیاست، کد اجراشده و Contextهای ذخیره‌شدهٔ واقعی باید با هم تطبیق داده شوند. وجود گزینهٔ تنوع در NB16 به‌تنهایی فعال‌بودن آن در مسیر نهایی را ثابت نمی‌کند.

## نتایج اجرای جدید

شناسهٔ سل، تعداد مقایسه‌ها، تعداد بازپخش‌های دقیق، نتایج Metric، اختلاف دو بازو، کنترل‌ها و مسیر و هش خروجی جدید در مواد همین گفتگو موجود نیستند؛ عدد یا شناسه‌ای برای آن‌ها ساخته نشده است. دربارهٔ اندازه یا جهت اثر حذف محدودیت در اجرای نهایی، مطمئن نیستم.

برای تکمیل گزارش فنی، **خروجی موجود همان اجرای موفق** مصرف شود؛ تهیهٔ گزارش به‌تنهایی نیازمند تکرار آزمایش یا API نیست.

| بخش | شواهد موردنیاز برای تکمیل همین سند |
| --- | --- |
| منشأ | نوت‌بوک، سل، نسخه، مسیر و هش Artifactها |
| سیاست واقعی | سقف منبع و سند و سایر قواعد، با شاهد کد فعال |
| خط پایه | تطبیق بازپخش با Contextهای ذخیره‌شده و علل اختلاف احتمالی |
| تغییر آزمایش | جزء دقیق حذف‌شده و قواعدی که ثابت مانده‌اند |
| ورودی مشترک | Query، نامزدهای رتبه‌بندی‌شده، ترتیب، بودجه و سایر عوامل مرتبط |
| جمعیت | تعداد مقایسه‌های زوجی، حذف‌ها، Missing و خطاهای نگاشت |
| معیارها | تعریف Relevance، مخرج، نتایج هر بازو و Delta |
| اثر واقعی | تعداد Contextهای تغییرکرده و نوع تغییر در انتخاب منابع یا اسناد |
| عدم قطعیت | فقط برآورد محاسبه‌شده و قابل ردیابی، در صورت وجود |
| هزینه | API و هزینهٔ اجرای اصلی، مستقل از تهیهٔ گزارش |

بازپخش دقیق خط پایه، اعتبار بازسازی آن را نشان می‌دهد؛ به‌تنهایی اثر حذف سقف یا کیفیت پاسخ را ثابت نمی‌کند. اگر حذف سقف برای بعضی Queryها هیچ تغییری ایجاد نکرده باشد، این موارد باید در جمعیت و تفسیر نتیجه محفوظ باشند.

## حدود استنتاج

- تغییر در تعداد منابع یا اسناد، به‌تنهایی بهبود یا افت پاسخ را اثبات نمی‌کند.
- عضویت شاهد مرجع در Context با پشتیبانی معنایی همهٔ ادعاهای پاسخ یکسان نیست.
- اثر Context با اثر Retrieval اولیه و اثر Reranker اشتباه نشود.
- نتیجهٔ حذف یک سقف مشخص به تمام سیاست‌های Source diversity تعمیم داده نشود.
- معیارهای کیفیت و پوشش مرجع با قرارداد و مخرج مستقل خود گزارش شوند؛ عدم قطعیت ناموجود حدس زده نشود.
