## نتایج و منشأ

تنها شاهد تکمیل در دسترس این نوبت، اعلام صریح کاربر است. تعداد موارد، شناسهٔ سل، تنظیمات دو بازو، نتیجهٔ Metric، Delta، عدم قطعیت، هزینه و هش Artifact ارائه نشده‌اند و در این گزارش حدس زده نمی‌شوند. دربارهٔ اندازه یا جهت اثر قطعه‌بندی، مطمئن نیستم.

برای تکمیل همین گزارش از **خروجی موجود همان اجرا** استفاده شود؛ تهیهٔ گزارش به‌تنهایی نیاز به بازاجرای Notebook یا API تازه ندارد. اطلاعات لازم عبارت‌اند از:

| بخش | شاهد لازم برای ثبت در نسخهٔ نهایی |
| --- | --- |
| منشأ اجرا | نوت‌بوک، شناسهٔ سل، نسخه یا Commit و رسید خروجی |
| دو بازوی واقعی | الگوریتم، اندازه و overlap قطعه‌ها و قواعد مرزبندی |
| داده و Index | نسخهٔ Corpus و Artifactهای جدا از نسخهٔ فریز‌شده |
| عوامل کنترل‌شده | مدل Embedding، Query، تنظیمات Retrieval و عمق رتبه در دامنهٔ مرتبط |
| مرجع | تعریف Relevance و نگاشت Gold سازگار با هر دو روش |
| جمعیت | تعداد زوج‌های ارزیابی‌شده، حذف‌ها، Missing و خطاهای نگاشت |
| اثر | Metric هر بازو، اختلاف و عدم قطعیت در صورت وجود محاسبهٔ معتبر |
| محدودیت | دامنهٔ واقعی مقایسه و حدود تعمیم به کیفیت پاسخ یا محصول |
| مصرف | API و هزینهٔ اجرای اصلی، جدا از تهیهٔ این گزارش |

نتیجهٔ Retrieval به‌تنهایی کیفیت پاسخ، پشتیبانی معنایی کامل یا صحت استناد را اثبات نمی‌کند. نتیجهٔ یک بازوی مشخص نیز به تمام مسیر محصول تعمیم داده نمی‌شود.
