## هدف و قرارداد

متن اقدام ۳۷ در چک‌لیست، طبق خواندن قبلی آن در همین گفتگو:

> بدون Citation verifier؛ تعیین verifier واقعی و اثر غیرفعال‌سازی آن؛ داوری Agent جای verifier مستقل معرفی نشود.

شرط عمومی Ablationها، تغییر واقعی جزء، کنترل سایر عوامل و ثبت اثر و محدودیت است. مقایسهٔ بی‌تغییر یا Proxy نباید جای Ablation کامل معرفی شود.

نخست باید مشخص باشد کنترل واقعاً پیاده‌سازی‌شده چیست: کنترل ساختار یا Locator، تطبیق با منبع، بررسی معنایی، Gate پذیرش یا ترکیبی از آن‌ها. نام‌گذاری همهٔ این‌ها به‌عنوان verifier معنایی بدون شاهد مجاز نیست. خروجی داور مدل نیز به‌تنهایی وجود verifier مستقل در مسیر تولید را ثابت نمی‌کند.

## نتیجهٔ موجود و حدود گزارش

در مواد همین گفتگو، تعداد موارد، شناسهٔ سل، نتایج کنترل‌های روشن/خاموش، اختلاف دو بازو و مسیر و هش Artifact جدید ارائه نشده‌اند. دربارهٔ نتیجهٔ نهایی اقدام ۳۷ مطمئن نیستم؛ عدد، شناسه یا حکم تکمیل برای آن ساخته نشده است.

برای تکمیل این سند، خروجی موجود اجرای نهایی مصرف شود؛ صرف تهیهٔ گزارش نیازی به بازاجرای Notebook یا API ندارد.

## محتوای لازم برای نسخهٔ فنی نهایی

| موضوع | شاهد موردنیاز |
| --- | --- |
| منشأ | نوت‌بوک، سل، نسخه، مسیر و هش ورودی‌ها و خروجی‌ها |
| کنترل واقعی | محل کد فعال و تعریف دقیق کنترل‌های قابل روشن/خاموش‌کردن |
| اتصال نسخه | شناسه و هش پاسخ خام و منتخب، استناد و منبع مرتبط |
| مقایسهٔ کنترل‌شده | ثابت‌بودن ورودی، قواعد recovery و سایر عوامل؛ تنها کنترل موردنظر تغییر کند |
| جمعیت و مخرج | تعداد کل، زوج‌های معتبر، خودداری‌ها، شکست‌های مشترک و اتصال‌های حل‌نشده به تفکیک |
| اثر | عبور/رد یا تغییر خروجی هر بازو، موارد اختلاف و معنای محدود آن |
| اعتبار معنایی | مرجع و روش ارزیابی صحت استناد، مستقل از صرف ساختار یا تصمیم Gate |
| محدودیت | تمایز بازپخش آفلاین از رفتار زنده و کنترل واقعی از verifier ایدئال |
| مصرف | API و هزینهٔ اجرای اصلی، مستقل از تهیهٔ این گزارش |

شکست مشترک بالادست نباید به اثر کنترل استناد نسبت داده شود. موارد فاقد اتصال نسخه نیز نتیجهٔ منفی یا مثبت کنترل محسوب نشوند. تعداد کل حساب‌شده با مخرج مقایسهٔ زوجی یکسان فرض نشود.

تغییر در پذیرش پاسخ، به‌تنهایی بهبود صحت معنایی استناد را اثبات نمی‌کند. اگر مقایسه فقط کنترل‌های پیاده‌سازی‌شده را روی مواد ذخیره‌شده بازپخش کرده باشد، نتیجه باید در همان دامنه گزارش شود؛ به رفتار مولد زنده یا verifier معنایی کامل تعمیم داده نشود.

## اقدامات این نوبت

فقط خواندن وضعیت مخزن و تهیهٔ سند انجام شد. هیچ Notebook، داوری، API مدل، retry یا محاسبهٔ تازهٔ Metric اجرا نشد. مصرف اجرای اصلی اقدام ۳۷ از اطلاعات در دسترس این نوبت معلوم نیست. این سند به مخزن Push نشده و مبنای تیک خودکار نیست.
