# گزارش اقدام ۴۵ — ارزیابی Gate کیفیت و رگرسیون

تاریخ: 2026-10-28

## نتیجهٔ اصلی

**گزارش ارزیابی اقدام ۴۵ کامل است؛ Gate کیفیت با آستانه‌های فریز‌شده رد شده و موارد BLOCKED محفوظ‌اند.** اجرای موفق سل به معنی قبولی کیفیت نیست. تیک یا عبارت «Gate پاس شد» با این نتیجه سازگار نیست.

این سند براساس جمع‌بندی صریح کاربر دربارهٔ خروجی **C081** در همین گفتگو تهیه شده است. نوت‌بوک، فایل‌های گزارش و محاسبات روی سیستم کاربر در تهیهٔ این سند مستقلاً بازخوانی یا اجرا نشده‌اند.

## هدف اقدام

ارزیابی Regression Gate با آستانه‌های فریز‌شده و ثبت وضعیت واقعی PASS / FAIL / BLOCKED؛ تفکیک موفقیت اجرای بررسی از پذیرش کیفیت محصول و مشخص‌کردن شروط احرازنشده.

## Gateهای مطلق کیفیت

| سنجه | نتیجهٔ فعلی اعلام‌شده | حد لازم فریز‌شده | وضعیت |
| --- | --- | --- | --- |
| Recall@10 | ۶۳٫۴۳٪ | ۸۵٪ | FAIL |
| nDCG@10 | ۰٫۵۷۳۵ | ۰٫۷۵ | FAIL |

هر دو سنجه پایین‌تر از حد لازم‌اند. این وضعیت، شکست اجرای سل نیست؛ نتیجهٔ مقایسه با قرارداد پذیرش است. آستانه‌ها برای تبدیل نتیجه به PASS تغییر داده نشده‌اند و این گزارش نیز مجوز تغییر آن‌ها نیست.

## عدم‌افت نسبت به خط پایه

**هر ۸ کنترل عدم‌افت بازیابی PASS شده‌اند.** طبق جمع‌بندی ارائه‌شده، نتایج نسبت به خط پایه بهتر شده‌اند؛ با این حال حدود مطلق کیفیت احراز نشده‌اند.

کنترل عدم‌افت، با حد مطلق پذیرش دو پرسش متفاوت را می‌سنجد. PASS کنترل‌های نسبی، FAIL حدود مطلق را خنثی نمی‌کند. تعداد هشت کنترل با تعداد ۱۶ سنجه جمع نمی‌شود؛ رابطهٔ جزئی نگاشت کنترل‌ها و سنجه‌ها در پیام مبنا ارائه نشده است.

## وضعیت سنجه‌ها و تست‌ها

| مجموعه | وضعیت اعلام‌شده |
| --- | --- |
| ۱۶ سنجه | ۲ PASS، دو FAIL و ۱۲ BLOCKED |
| کنترل‌های عدم‌افت بازیابی | هر ۸ کنترل PASS |
| ۳۲۲ تست رگرسیون | اجرا نشده؛ BLOCKED |
| پذیرش NB19/NB20 در ورودی این بررسی | احراز نشده |
| API جدید | صفر |

جمع وضعیت سنجه‌ها برابر ۱۶ است. BLOCKED به معنی نبود امکان احراز در ورودی یا وضعیت فعلی بررسی است؛ FAIL اندازه‌گیری‌شده محسوب نمی‌شود. **۳۲۲ تست اجرا‌نشده، ۳۲۲ تست شکست‌خورده نیستند.**

نام دو سنجهٔ PASS و جزئیات علت هر یک از ۱۲ BLOCKED در پیام مبنا ارائه نشده‌اند و در این سند حدس زده نشده‌اند. برای مصرف فنی باید به جدول و رسیدهای اصلی C081 رجوع شود.

## پذیرش بالادست و حدود تفسیر

پذیرش NB19/NB20 در ورودی این بررسی احراز نشده است. این مشاهده به معنی انجام‌نشدن کارهای قبلی، نبود همهٔ شواهد در پروژه یا لزوم بازاجرای آن کارها نیست. پیش از هر کار تازه باید اتصال به تصمیم‌ها و شواهد موجود بررسی شود.

رد دو حد مطلق، نتیجهٔ واقعی Gate در این قرارداد است؛ از آن درصد کیفیت کلی محصول، بی‌اعتباری همهٔ خروجی‌ها یا شکست تمام پروژه نتیجه گرفته نمی‌شود. در مقابل، بهبود نسبی نیز پذیرش نهایی NB21 یا محصول زنده را ثابت نمی‌کند.

## دامنهٔ پایان اقدام ۴۵

کار گزارش‌کردن نتیجهٔ Gate پایان یافته است؛ شروط کیفیت و اجرای تست‌های مسدودشده پایان نیافته‌اند. در صورت ثبت تکمیل فعالیت، قید زیر باید همراه آن بماند:

> ارزیابی و گزارش Gate کامل؛ دو سنجه FAIL و ۱۲ سنجه BLOCKED؛ ۳۲۲ تست اجرا نشده‌اند؛ Gate کیفیت پاس نشده است.

این قید، پیشنهاد متن برای حفظ دامنه است؛ در این نوبت تیک چک‌لیست تغییر نکرده است. هیچ حکم پذیرش نهایی از تکمیل گزارش حاصل نمی‌شود.

## انتقال به اقدام ۴۶

بستهٔ تحویل می‌تواند با وضعیت واقعی FAIL/BLOCKED تهیه شود؛ این انتقال وضعیت نباید به پذیرش کیفیت تبدیل شود. بسته باید شامل نتیجهٔ دو حد مطلق، وضعیت ۱۶ سنجه، هشت کنترل عدم‌افت، تست‌های اجرا‌نشده و شرط احرازنشدهٔ NB19/NB20 باشد.

برای تعیین کار اصلاحی، ابتدا منشأ هر BLOCKED، شواهد موجود و مالک بررسی آن مشخص شود. بازاجرای جمعیت، داوری تازه، تغییر آستانه یا اجرای API از این گزارش مجوز نمی‌گیرد. انجام یا آغاز اقدام ۴۶ نیز در این سند ادعا نمی‌شود.

## ردیابی و تحویل

شناسهٔ سل مبنا C081 است. مسیر فایل‌ها، هش Artifactها، نسخهٔ آستانه‌های فریز‌شده، مخرج دقیق سنجه‌ها و جزئیات تمام کنترل‌ها در پیام مبنا ارائه نشده‌اند؛ در این سند برای آن‌ها مقدار فرضی ساخته نشده است. اصل گزارش‌های تولیدشده روی سیستم کاربر مرجع ردیابی فنی باقی می‌ماند.

در تهیهٔ این سند هیچ Notebook، API مدل، داوری، تست، محاسبهٔ تازه یا عملیات مخزن انجام نشد. مخزن و تیک‌ها تغییر نکردند؛ گزارش به مخزن Push نشده است. API صفر اعلام‌شده مربوط به بررسی مبناست و هزینهٔ تاریخی محصول یا کل پروژه را صفر نمی‌کند.
