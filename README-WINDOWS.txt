RAG Finance - Windows

1. برنامه را نصب کنید یا فایل ZIP را Extract کنید.
2. فایل .env را با تنظیمات API معتبر کنار RAG-Finance.exe قرار دهید.
3. RAG-Finance.exe را اجرا کنید.
4. برنامه پس از آماده شدن در مرورگر پیش فرض باز می شود.

داده های قابل تغییر برنامه در پوشه LocalAppData کاربر ذخیره می شوند.
برای اجرای برنامه نیازی به نصب Python، Git، Docker یا Qdrant Server نیست.
